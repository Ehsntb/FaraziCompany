# Farazi Company

وب‌سایت معرفی فرازی کمپانی با HTML، CSS و JavaScript خالص؛ دارای صفحات خانه، درباره ما، فهرست محصولات و تماس با ما در دو زبان فارسی و انگلیسی.

## امکانات

- طراحی واکنش‌گرا با رنگ‌های تیره و مسی، لوگوی پروژه و فونت محلی Vazirmatn.
- آدرس مستقل برای هر زبان، با جهت RTL برای فارسی و LTR برای انگلیسی.
- فهرست محصولات از یک فایل داده قابل ویرایش و انتخاب محصولات صفحه اصلی.
- گالری، نمایش جزئیات محصولات، منوی موبایل و فرم آماده‌سازی ایمیل.
- HTML ثابت محصولات، متادیتای اختصاصی صفحات و ابزار تولید تنظیمات SEO.

## اجرای سریع

برای مشاهده نسخه آماده، فایل `index.html` را در مرورگر باز کنید. نصب پکیج، فریم‌ورک یا بک‌اند لازم نیست.

برای پیش‌نمایش با سرور محلی، در ریشه پروژه اجرا کنید:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

سپس [پیش‌نمایش فارسی](http://127.0.0.1:8080/index.html) یا [پیش‌نمایش انگلیسی](http://127.0.0.1:8080/index.en.html) را باز کنید.

روی هاست PHP، خروجی صفحات و SEO در هر درخواست از منابع ساخته می‌شود. Python 3 و Node.js فقط برای تولید نسخهٔ استاتیک اختیاری لازم‌اند.

```text

├── about.html / about.en.html
├── products.html / products.en.html
├── contact.html / contact.en.html
├── styles.css              # استایل عمومی، خانه، هدر و فوتر
├── pages.css               # استایل صفحات داخلی
├── script.js               # تعاملات، محصولات و فرم تماس
├── products-data.js        # منبع داده محصولات
├── seo-config.json         # دامنه، عنوان و توضیحات صفحات
├── robots.txt
├── scripts/

```

فایل `sitemap.xml` برای دامنه اصلی پروژه تولید شده است و با اجرای ابزار SEO به‌روز می‌شود.

## ویرایش متن و ترجمه

متن فارسی و ساختار را در چهار فایل HTML فارسی ویرایش کنید. ترجمه متن‌های ثابت در ویژگی `data-en` همان عنصر قرار دارد:

```html
<span data-en="Contact us">تماس با ما</span>
```

فایل‌های `*.en.html` خروجی تولیدشده‌اند؛ تغییر مستقیم آن‌ها در اجرای بعدی بازنویسی می‌شود. عنوان و توضیحات SEO هر صفحه را در `seo-config.json` تغییر دهید.

روی هاست PHP، ویرایش متن، ترجمه یا محصولات در درخواست بعدی اعمال می‌شود. فقط برای بازسازی نسخهٔ استاتیک، از ریشه پروژه اجرا کنید:

```powershell
python scripts/build-seo.py
```

این دستور چهار صفحه فارسی را به‌روز و چهار نسخه انگلیسی را تولید می‌کند. خروجی‌های تغییرکرده را همراه فایل‌های منبع کامیت و منتشر کنید.

## ویرایش محصولات

تنها منبع محصولات، آرایه `window.FARAZI_PRODUCTS` در `products-data.js` است. ساختار هر محصول به‌شکل زیر است:

```js
{
  "name": {
    "fa": "نخ پنبه",
    "en": "Cotton yarn"
  },
  "description": {
    "fa": "توضیحات فارسی محصول",
    "en": "English product description"
  },
  "images": [
    "assets/products/cotton-01.webp",
    "assets/products/cotton-02.webp"
  ],
  "featured": false,
  "showOnHome": true
}
```

| فیلد | کاربرد |
| --- | --- |
| `name` | نام فارسی و انگلیسی |
| `description` | توضیحات فارسی و انگلیسی به‌صورت متن ساده |
| `images` | فهرست عکس‌های گالری، نسبت به ریشه پروژه؛ نخستین عکس تصویر اصلی است |
| `featured` | نمایش محصول با چیدمان بزرگ و شاخص در صفحه محصولات |
| `showOnHome` | نمایش در خانه با `true` و مخفی‌کردن از خانه با `false` |

ترتیب آرایه، ترتیب نمایش است. در نسخه فعلی شش گروه محصول ثبت شده و «نخ لمه و متالیک» محصول شاخص است. صفحه محصولات و گالری تمام رکوردها را نشان می‌دهند؛ `showOnHome` فقط صفحه اصلی را کنترل می‌کند. برای افزودن محصول، یک شیء را کپی و مقادیرش را تغییر دهید. برای حذف، همان شیء را از آرایه بردارید.

بعد از تغییر داده‌ها، دستور تولید را اجرا کنید تا محتوای HTML اولیه و داده‌های ساختاریافته نیز هماهنگ شوند. تغییر فقط فایل JavaScript، خروجی ثابت قابل ایندکس را به‌روز نمی‌کند.

## رفتار زبان‌ها

انتخاب زبان، یک لینک واقعی به همان صفحه در زبان دیگر است. لینک‌های داخلی نیز زبان انتخابی را حفظ می‌کنند. `lang` و `dir` در HTML هر نسخه تنظیم شده‌اند؛ زبان آدرس بازشده بر تنظیم ذخیره‌شده مرورگر اولویت دارد. لینک‌های قدیمی دارای `?lang=en` یا `?lang=fa` با JavaScript به نسخه متناظر هدایت می‌شوند.

## اطلاعات تماس و فرم

اطلاعات تماس تأییدشده کارفرما—تلفن ثابت، موبایل/واتساپ، فکس، ایمیل، تلگرام و نشانی—در چهار صفحه فارسی قرار دارد. برای تغییر آن‌ها، هم متن و هم `href` را در فایل‌های فارسی و ایمیل مقصد فرم را در `script.js` اصلاح کنید؛ سپس نسخه‌های انگلیسی را دوباره تولید کنید.

فرم تماس ورودی‌ها را اعتبارسنجی و لینک `mailto:` آماده می‌کند. ارسال نهایی در برنامه ایمیل کاربر انجام می‌شود؛ سایت پیام‌ها را روی سرور ذخیره یا ارسال نمی‌کند.

لینک‌های واتساپ، تلگرام و کارت دیجیتال شرکت در فوتر قرار دارند. سال فوتر هنگام تولید و هنگام بارگذاری صفحه از تاریخ جاری گرفته می‌شود.

## تنظیمات SEO

صفحات دارای عنوان و توضیحات اختصاصی، Open Graph، Twitter Card و JSON-LD هستند. متن محصولات در HTML اولیه موجود است و برای خواندن آن به اجرای JavaScript نیاز نیست.

برای تغییر تنظیمات انتشار:

1. در `seo-config.json` مقدار `siteUrl` را به آدرس واقعی HTTPS سایت، بدون اسلش پایانی، تغییر دهید.
2. مقادیر `siteName`، `socialImage` و عنوان و توضیحات دو زبان را بررسی کنید.
3. روی هاست PHP فایل منبع را آپلود کنید؛ برای نسخهٔ استاتیک دستور `python scripts/build-seo.py` را اجرا کنید.

ابزار موارد زیر را می‌سازد:

- canonical مستقل هر صفحه و زبان.
- hreflang فارسی، انگلیسی و `x-default`.
- آدرس مطلق تصویر و صفحه برای اشتراک‌گذاری.
- آدرس‌های داده ساختاریافته و BreadcrumbList صفحات داخلی.
- نقشه هشت صفحه در `sitemap.xml` و ارجاع آن در `robots.txt`.

دامنه اصلی در `siteUrl` برابر `https://farazicompanyfc.com` است. اگر دامنه اصلی تغییر کرد، آن را در `seo-config.json` و سپس خروجی‌ها را با ابزار تولید به‌روز کنید.

## انتشار

سایت روی هاست استاتیک قابل میزبانی است. هشت فایل HTML، دو فایل CSS، فایل‌های `script.js` و `products-data.js`، پوشه‌های `assets/` و `logo/` و فایل‌های `robots.txt` و `sitemap.xml` تولیدشده را با همان ساختار مسیرها بارگذاری کنید. اجرای Python یا Node.js روی هاست لازم نیست.

پیش از انتشار عمومی:

- اطلاعات تماس و فهرست محصولات را برای تغییرات احتمالی آینده دوباره با کارفرما تطبیق دهید.
- HTTPS و یک میزبان اصلی را تنظیم و نسخه‌های دیگر را با پاسخ 301 هدایت کنید.
- آدرس `/` و `/index.html` را با سیاست canonical تولیدشده هماهنگ کنید.
- برای مسیر ناموجود پاسخ واقعی 404 بدهید و دسترسی به robots.txt را بررسی کنید.
- فشرده‌سازی و کش منابع را در هاست تنظیم کنید؛ پس از تغییر فایل‌های بدون هش، کش را به‌روز کنید.
- نقشه سایت را در Google Search Console ثبت و ایندکس صفحات و Core Web Vitals را پس از انتشار بررسی کنید.

تنظیمات سرور، ثبت در Search Console و اندازه‌گیری عملکرد واقعی با ابزار تولید این مخزن انجام نمی‌شوند.

## بررسی پس از تغییر

```powershell
node --check script.js
node --check products-data.js
python scripts/build-seo.py
git diff --check
```

سپس هر چهار صفحه را در دو زبان بررسی کنید: تغییر زبان، جهت متن، لینک‌های داخلی، فهرست محصولات، منوی موبایل و آماده‌سازی پیش‌نویس تماس. عنوان و توضیحات، تعداد محصولات HTML و آدرس‌های canonical و hreflang را نیز در سورس صفحات کنترل کنید.

## تصاویر و فونت

عکس‌های واقعی ارسال‌شده توسط کارفرما، بهینه‌سازی و با فرمت WebP در `assets/products/` قرار گرفته‌اند و گالری محصولات از همین فایل‌ها استفاده می‌کند. تصاویر تزئینی تولیدشده در `assets/generated/` قرار دارند؛ تصویر بازار و نقشه تجارت جنبه تصویرسازی دارند و پرامپت‌ها در `assets/generated/prompts.json` ثبت شده‌اند.

لوگوهای پروژه در `logo/` و فونت محلی Vazirmatn به‌همراه مجوز SIL OFL در `assets/fonts/` قرار دارند.

## آرشیو چت کارفرما

فایل `private/farazi-whatsapp-chat.html` چت قابل جست‌وجو را نمایش می‌دهد. فایل‌های اصلی عکس و صدا در `private/farazi-whatsapp-media/` همراه آرشیو در گیت نگهداری می‌شوند. برای نمایش مدیا، این پوشه باید کنار HTML باقی بماند.

برای بازسازی از خروجی واتساپ:

```powershell
python scripts/build-chat-archive.py "C:\Users\ehsntb\Downloads\WhatsApp Chat @FaraziCompanyFC" private/farazi-whatsapp-chat.html
```

پیش از انتقال سایت به هاست، می‌توانید پوشهٔ `private/` را کامل حذف کنید.

## گالری مستقل هدر

عکس‌های گالری در `assets/gallery/` و تصاویر محصولات در `assets/products/` هستند. روی هاست PHP، با هر بار باز کردن گالری، `gallery.php` فهرست فعلی پوشه را می‌خواند. کافی است عکس JPG، JPEG، PNG، WebP، GIF یا AVIF را در پوشهٔ گالری آپلود کنید؛ نیازی به اجرای دستور یا ویرایش فهرست نیست. حذف عکس نیز در باز شدن بعدی گالری اعمال می‌شود.

فایل `gallery.php` را در ریشهٔ سایت، کنار `index.html` و `script.js`، منتشر کنید. پوشهٔ گالری باید برای PHP قابل خواندن باشد. برای پیش‌نمایش همین رفتار روی سیستم دارای PHP:

```powershell
php -S 127.0.0.1:8081
```

فایل `gallery-data.js` فقط فهرست جایگزین برای باز کردن مستقیم HTML یا پیش‌نمایش بدون PHP است. برای به‌روز کردن این نسخهٔ محلی، `python scripts/build-gallery.py` را اجرا کنید؛ گزینهٔ `--watch` نیز برای پایش محلی موجود است. اجرای ابزار SEO این فهرست جایگزین را بازسازی می‌کند.

## به‌روزرسانی خودکار روی هاست PHP

برای حالت خودکار، PHP نسخهٔ ۸ یا جدیدتر با افزونهٔ DOM و هاست Apache/LiteSpeed با پشتیبانی از `.htaccess` و rewrite لازم است. فایل‌های `site.php`، `.htaccess` و `gallery.php` را همراه HTML، `products-data.js`، `seo-config.json` و دارایی‌های سایت آپلود کنید. آدرس‌های قبلی `.html` حفظ می‌شوند. فایل‌ها در سرور بازنویسی نمی‌شوند؛ خروجی از منابع فعلی ساخته می‌شود.

| تغییر | منبع قابل ویرایش | نتیجه بدون اجرای دستور |
| --- | --- | --- |
| عکس گالری | `assets/gallery/` | شناسایی در باز شدن بعدی گالری |
| متن صفحات | `index.html`، `about.html`، `products.html`، `contact.html` | نمایش متن فارسی تازه |
| ترجمه انگلیسی | ویژگی `data-en` در همان فایل‌های فارسی | تولید خودکار صفحه انگلیسی؛ ترجمه باید توسط شما وارد شود |
| محصولات | `products-data.js` | کارت‌ها، جزئیات و دادهٔ ساختاریافته محصولات |
| عنوان، توضیحات و دامنه | `seo-config.json` | متادیتا، canonical، hreflang، sitemap و robots |
| سال فوتر | تاریخ سرور | به‌روزرسانی خودکار |

آرایهٔ `products-data.js` باید JSON معتبر بماند: کلیدها و رشته‌ها داخل کوتیشن دوتایی، بدون کامنت یا ویرگول اضافه در آرایه. نام و توضیحات هر محصول باید هر دو زبان را داشته باشند. افزودن عکس به پوشهٔ محصولات به‌تنهایی تعیین نمی‌کند عکس متعلق به کدام محصول است؛ مسیر آن را در `images` محصول ثبت کنید.

پیش‌نمایش کامل خودکار روی کامپیوتر:

```powershell
php -S 127.0.0.1:8082 router.php
```

سپس `http://127.0.0.1:8082/` را باز کنید. در هاست، `.htaccess` همین مسیرها را هدایت می‌کند؛ روی Nginx باید مسیرهای هشت صفحه، `sitemap.xml` و `robots.txt` به `site.php?page=...` هدایت شوند. راه‌اندازی هاست واقعی در این تغییر انجام نشده است.

### پایش خودکار آرشیو چت در کامپیوتر

```powershell
python scripts/build-chat-archive.py "C:\Users\ehsntb\Downloads\WhatsApp Chat @FaraziCompanyFC" private/farazi-whatsapp-chat.html --watch
```

تا زمانی که دستور باز است، تغییر `_chat.txt` یا فایل‌های همراه، آرشیو را دوباره می‌سازد. هاست به پوشهٔ Downloads کامپیوتر دسترسی ندارد؛ این بخش محلی است. فایل‌های خروجی چت را فقط در صورت نیاز جداگانه منتقل کنید.

## صفحات موضوعی و بررسی SEO

صفحهٔ `products.html` برای معرفی انواع نخ، `lame-yarn.html` برای مشخصات و استعلام نخ لمه و `fancy-yarn.html` برای راهنمای نخ فانتزی است. نسخه‌های انگلیسی با پسوند `.en.html` ساخته می‌شوند. مسیرهای جدید در PHP، `.htaccess` و نقشهٔ سایت ثبت شده‌اند؛ مجموع صفحات دوزبانه ۱۲ صفحه است. متن هر صفحه در فایل فارسی و ترجمه در `data-en` ویرایش می‌شود.

برای بررسی خودکار خروجی‌ها، `python scripts/check-seo.py` و برای سرور محلی، `python scripts/check-seo.py --base-url http://127.0.0.1:8082/` را اجرا کنید. جزئیات تغییرات، منابع رسمی گوگل و اقدامات انتشار و Search Console در `SEO-NOTES.md` آمده است.
