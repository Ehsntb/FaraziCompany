# Farazi Company

سایت معرفی فرازی کمپانی، ساخته‌شده صرفاً با HTML، CSS و JavaScript بر اساس تصویر مرجع.

## اجرا

فایل `index.html` را در مرورگر باز کنید. نصب پکیج یا مرحله build لازم نیست؛ تصاویر و فونت به‌صورت محلی قرار دارند و صفحه بدون اینترنت هم نمایش داده می‌شود.

برای پیش‌نمایش با سرور محلی، در پوشه پروژه اجرا کنید:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

سپس نشانی http://127.0.0.1:8080 را باز کنید.

## فایل‌ها

- `index.html`: ساختار صفحه، اطلاعات تماس و آیکون‌های SVG.
- `styles.css`: رنگ‌ها، تایپوگرافی، چیدمان دسکتاپ و موبایل.
- `products-data.js`: تنها منبع اطلاعات محصولات، شامل نام و توضیحات دوزبانه، عکس و گزینه نمایش در صفحه اصلی.
- `products.html`: فهرست کامل محصولات با نام، توضیحات و عکس.
- `script.js`: نمایش محصولات، گالری، منوی موبایل، فرم تماس و تغییر زبان.
- `logo/`: لوگوهای اصلی پروژه؛ لوگوی کامل در سربرگ و نشان در favicon.
- `assets/generated/`: ده تصویر اختصاصی بازتولیدشده؛ هفت محصول، بنر، معماری بازار و نقشه تجارت. اصل PNG و نسخه WebP با وضوح کامل هر تصویر نگهداری شده‌اند.
- `assets/reference-artwork.jpeg`: مرجع اولیه طراحی؛ سایت دیگر از این تصویر برای نمایش عکس‌ها استفاده نمی‌کند.
- `assets/fonts/`: فونت محلی Vazirmatn و مجوز SIL OFL.

## ویرایش محتوا

اطلاعات تماس فعلی، سابقه شرکت و سال کپی‌رایت از تصویر مرجع برداشته شده‌اند. قبل از انتشار عمومی آن‌ها را با اطلاعات واقعی شرکت در `index.html` جایگزین کنید. شماره واتساپ و تلفن را هم در متن و هم در `href` به‌روزرسانی کنید.

لینک واقعی Instagram و LinkedIn در مرجع مشخص نبود؛ دکمه‌های آن‌ها فعلاً پنجره توضیح و مسیر تماس را نشان می‌دهند. پس از دریافت نشانی رسمی، آن‌ها را به لینک تبدیل کنید.

تمام اطلاعات محصولات در `window.FARAZI_PRODUCTS` داخل `products-data.js` قرار دارند. توضیحات عمومی محصولات جایگزین مشخصات فنی واقعی نیستند. ترجمه متن‌های ثابت با ویژگی `data-en` در HTML و ترجمه محصولات در JavaScript تعریف شده است.

## تصاویر اختصاصی

همه ده تصویر با ابزار داخلی ImageGen برای این پروژه بازتولید شده‌اند. سبک مشترک: پس‌زمینه تیره، نور گرم استودیویی، رنگ‌های مشکی و مسی و جزئیات دقیق بافت نخ. طرح صفحه و لوگوهای اصلی حفظ شده‌اند.

نسخه‌های WebP با کیفیت 94 و بدون تغییر ابعاد برای بارگذاری سایت استفاده می‌شوند؛ فایل‌های اصلی PNG نیز در همان پوشه قرار دارند. تصویر معماری، تصویرسازی الهام‌گرفته از بازار تهران است؛ نقشه تجارت هم جنبه تصویری دارد. تصاویر محصولات تولیدشده‌اند و عکاسی از موجودی واقعی شرکت نیستند.

پرامپت کامل هر تصویر و فهرست فایل‌ها در `assets/generated/prompts.json` ثبت شده است.

## صفحات داخلی و زبان

- `about.html`: معرفی شرکت، سابقه، ارزش‌ها و حوزه فعالیت.
- `contact.html`: راه‌های ارتباطی، نشانی و فرم آماده‌سازی ایمیل.
- `pages.css`: استایل صفحات داخلی.

هر چهار صفحه فارسی و انگلیسی هستند. ویژگی‌های `lang` و `dir` با تغییر زبان به‌روز می‌شوند و جهت چیدمان، فرم و فلش‌ها هماهنگ می‌شود. انتخاب زبان با پارامتر `?lang=fa` یا `?lang=en` و ذخیره محلی حفظ می‌شود.

فرم تماس پیام را اعتبارسنجی و یک پیش‌نویس `mailto:` آماده می‌کند؛ ارسال نهایی در برنامه ایمیل کاربر انجام می‌شود. سایت سرویس ارسال ایمیل یا بک‌اند ندارد.

## ویرایش محصولات

برای تغییر محصول فقط فایل `products-data.js` را ویرایش کنید. ساختار هر محصول دقیقاً چهار فیلد دارد:

```js
{
  name: {
    fa: "نخ پنبه",
    en: "Cotton yarn"
  },
  description: {
    fa: "توضیحات فارسی محصول",
    en: "English product description"
  },
  image: "assets/generated/cotton.webp",
  showOnHome: true
}
```

- `name`: نام در هر دو زبان.
- `description`: توضیحات در هر دو زبان؛ متن ساده است و HTML اجرا نمی‌شود.
- `image`: مسیر عکس مشترک برای هر دو زبان، نسبت به پوشه اصلی سایت.
- `showOnHome`: مقدار بولی `true` برای نمایش در صفحه اصلی و `false` برای مخفی‌کردن فقط از صفحه اصلی. مقدار را داخل کوتیشن نگذارید.

صفحه محصولات و گالری همیشه تمام محصولات را نشان می‌دهند. در حال حاضر هر هفت محصول برای نمایش در صفحه اصلی فعال هستند. ترتیب آرایه همان ترتیب نمایش است. برای افزودن محصول، یکی از اشیای آرایه را کپی و چهار فیلد آن را ویرایش کنید؛ برای حذف، شیء مربوط را بردارید. سپس مرورگر را بازخوانی کنید.

داده‌ها به شکل JavaScript جدا ذخیره شده‌اند تا حتی با بازکردن مستقیم فایل HTML، بدون سرور یا fetch نیز کار کنند.
